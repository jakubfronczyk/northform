# Architecture Decision Records

Public, tracked. One ADR per architectural decision that needs its *why* preserved: the context,
the choice, the alternatives rejected, the consequences. Numbered `NNNN-title.md`, append-only;
supersede rather than rewrite.

ADRs are the public "why"; `docs/plans/decisions.md` (private) is the full D-log. Promote a
decision to an ADR when it shapes the architecture and a reader of the public repo should
understand the reasoning.

> Seeded empty on the Kotlin rewrite. The first ADRs will likely cover: the KMP/Compose choice and
> its native seam, the pure-reducer core, the ports-and-adapters (`expect/actual`) boundary, and
> the persistence engine.
